# Black Protocol

Independent third-person espionage RPG; not ShadowOps Tactical. Original story and assets. Godot 4 Compatibility for web feasibility. Keep systems modular and commits small. Build a playable vertical slice before adding extensive menus or content. Use actual engine screenshots for visual validation; label concept art separately. No automatic builds or deployment on every push; add focused validation and explicit export later. Never commit secrets or large binary assets. Test movement, collision, camera, and mission state in Godot before calling a feature validated.
